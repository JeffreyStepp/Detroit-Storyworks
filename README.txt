How to test:
1. Open index.html in a modern browser.
2. Use the category filters under Experiences.
3. In Discover Detroit, search "Motown" or use a suggested search.
4. Confirm a loading state appears and a Wikipedia result is displayed.
5. Try an unusual/nonexistent search to observe the no-results state.
6. Temporarily break the API URL in script.js if you need to demonstrate the error state, then restore it.
7. Submit the inquiry form with missing fields, then with all fields completed.
8. Open developer tools and confirm there are no unexpected console errors.
9. Test at desktop and narrow mobile widths.

Deployment:
Create a GitHub repository containing the project files and deploy it with GitHub Pages or another static host approved by the instructor.
